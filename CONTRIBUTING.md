# Contributing to DeepVerse

DeepVerse is a cinematic, horror-inspired developer portfolio focused on immersive UI, motion, and creative frontend experiences.

## Areas to contribute

- Visual polish and responsive behavior
- Accessibility and interaction improvements
- Animation and motion refinement
- Performance and loading improvements
- Documentation and developer experience

## Development

```bash
npm install
npm run dev
```

Before submitting a change, test the affected experience across desktop and mobile layouts and make sure the project still builds successfully.

## Pull requests

Keep pull requests focused on one improvement, explain what changed and why, and include any relevant screenshots or testing notes for visual changes.
