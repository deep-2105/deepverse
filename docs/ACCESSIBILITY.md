# DeepVerse Accessibility Notes

DeepVerse is designed as an immersive portfolio, but visual effects should never be the only way to understand the content.

## Refinement checklist

- Keep meaningful content available as readable text.
- Use descriptive labels for interactive controls.
- Preserve keyboard access for navigation and important actions.
- Check text contrast against cinematic backgrounds.
- Avoid relying on animation alone to communicate state.
- Respect reduced-motion preferences when adding or refining motion.
- Test the portfolio at mobile, tablet, and desktop widths.

These notes are part of the ongoing portfolio refinement process and should be reviewed when new interactions or visual effects are introduced.
