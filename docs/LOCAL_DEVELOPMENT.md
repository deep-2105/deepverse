# Local Development

DeepVerse is developed locally before changes are published to the GitHub repository and deployed through Vercel.

## Setup

1. Install a supported Node.js version and npm.
2. Clone the repository.
3. Open the project directory in a terminal.
4. Install dependencies with `npm install`.
5. Start the Vite development server with `npm run dev`.

## Before committing

Run `npm run build` and resolve build errors before publishing. Review `git status` and the diff so generated files, local secrets, and unrelated changes are not committed.

## Project data

Keep portfolio facts and project links grounded in verified source data. Do not add invented education, employment, certifications, metrics, or repository URLs.
